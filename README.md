# Hospital System - Onion Architecture

### .Net Project Build with Onion Architecture

Divided into three Layers: Hospital.Domain, Hospital.Application, Hospital.Infrastructure.
Hospital.Domain contains the entities which Domain.Infrastructure Handels the data presistence.

## Key Features
Many to Many Relationships Modeling,
Rule Validation,
Automated Testing.

## Tech
C#(.Net Core),
Entity Framework Core,
SSMS, 
Onion Architecture
